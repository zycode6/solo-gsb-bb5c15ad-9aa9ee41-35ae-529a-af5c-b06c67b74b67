# 🎭 舞台走位校验（Stage Walk Check）

建立带**通行耗时**的舞台区域连接图，按时间为演员添加**到位口令**；系统按时间顺序计算相邻口令之间的**最短通行耗时（Dijkstra）**，自动标出**无法按时抵达**的区段，并给出「所需秒数 / 可用秒数 / 缺口秒数」与最短路径。任何编辑都会**即时重算**，并可一键**导出校验报告**（Markdown / JSON）。

技术栈：Node.js + Express + 原生 HTML/CSS/JavaScript（零前端构建、零前端框架）。

---

## 🚀 一条命令启动（推荐 Docker Compose）

```bash
docker compose up -d --build
```

启动后访问：

> **http://localhost:3000**

首次启动会自动完成：安装依赖 → 启动服务 → 载入随仓库分发的**示例舞台与走位数据**（8 个区域、14 条连接、3 名演员、11 条口令，内含「赶不到」「单向边不连通」等违规示例）。

停止：

```bash
docker compose down          # 数据保留在命名卷 stage-data 中
docker compose down -v       # 同时清空数据，下次启动重新初始化为示例
```

### 自定义端口

宿主机端口默认映射到 `3000`，可用 `PORT` 覆盖（容器内始终监听 3000）：

```bash
PORT=8080 docker compose up -d --build
# 然后访问 http://localhost:8080
```

## ⚙️ 配置（环境变量）

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `3000` | 服务监听端口（本地运行方式有效；Compose 下容器内固定 3000，宿主机端口用同名 `PORT` 变量映射） |
| `DATA_DIR` | `./data`（容器内 `/app/data`） | 运行时数据目录，`state.json` 存放在此 |

Compose 将 `/app/data` 挂载为命名卷 `stage-data`，因此重建容器不会丢失编辑结果；卷为空时以镜像内置示例初始化。

## 🧭 使用指南

界面为三栏布局：

1. **左栏 · 建模**
   - **区域**：添加舞台区域（如上场口、表演中区、台口、高台）；可在中间画布上**拖动节点**调整位置，**双击节点**改名。
   - **连接**：选择起点 / 终点并填写**通行秒数**；不勾选「单向」即为双向连接。同两个区域之间可建多条连接，计算自动取最短。
   - **演员**：添加演员并指定标记颜色。
   - **口令**：为演员添加到位口令，时间支持 `HH:MM:SS`、`MM:SS` 或纯秒数（如 `90`），另可填写备注。
2. **中栏 · 连接图**：SVG 画布，边上标注通行秒数；点击右侧校验区段会在图上**高亮最短路径**（绿色可按时抵达，红色无法按时）。
3. **右栏 · 校验结果**：汇总卡片 + 按演员分组的时间轴与区段明细，逐段列出所需最短秒数、可用秒数、缺口 / 余量与原因。

**即时重算**：任意增删改操作后约 350ms 自动保存并重算（顶栏显示「已保存并完成校验」），也可点「↻ 重新校验」手动触发。

**导出报告**：顶栏「⬇ 导出报告(MD)」下载 Markdown 报告（含区域表、每位演员的口令表与区段校验表）；「⬇ JSON」下载包含原始数据与结构化校验结果的 JSON。

「重置示例」按钮会放弃当前编辑、恢复内置示例数据。

## 🧮 校验规则

- 每位演员的口令按时间升序排序（同刻按 id 稳定排序），相邻两条构成一个**校验区段**。
- 用 **Dijkstra 最短路**计算两区域间最短通行耗时：双向连接两个方向都可走，单向连接只能 `起点 → 终点`。
- 「可用秒数」= 下一条口令时间 − 本条口令时间。
- 判定：
  - `所需最短 ≤ 可用` → ✅ 可按时抵达（报告给出余量秒数与具体路径）；
  - `所需最短 > 可用` → ❌ 无法按时抵达（标出所需、可用、缺口秒数）；
  - 两区域**不连通** → ❌ 无论多少时间都无法抵达；
  - 口令引用了已删除区域、时间格式非法等情况也会在区段中说明原因。

## 🔌 HTTP API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `GET` | `/api/state` | 获取当前区域 / 连接 / 演员 / 口令数据 |
| `PUT` | `/api/state` | 整体保存（服务端做规范化与校验，悬空引用自动丢弃） |
| `GET` | `/api/check` | 执行全量校验，返回结构化结果 |
| `GET` | `/api/report?format=markdown` | 下载 Markdown 报告（`format=json` 下载 JSON） |
| `POST` | `/api/reset` | 恢复内置示例数据 |
| `GET` | `/api/health` | 健康检查 |
